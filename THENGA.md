# THENGA OS

## Concept

THENGA OS is a browser-based interactive operating system simulation for a coconut.

The project is intentionally useless:
coconuts do not need an operating system.

## Important

This is NOT a real operating system or kernel.

It is an application-level OS simulation running in the browser.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- Lucide React
- Motion
- GitHub
- Vercel

## Architecture

UI → ThengaEngine → State / Events

## MVP

1. Boot screen
2. Desktop
3. Window system
4. Taskbar
5. Thenga Explorer
6. Thenga Terminal
7. Kola Manager
8. ThengaEngine
9. Shared state
10. Personality / error system

## Rules

- No real kernel.
- No real filesystem access.
- No unnecessary backend.
- No Supabase unless absolutely necessary.
- MVP before optional features.
- Prefer existing libraries.
- Keep code beginner-readable.
- Do not rewrite working code unnecessarily.
- Test after every major change.

## Optional Features

Only after MVP is stable:

- Calculator
- Recycle Bin
- Fake virus
- Coconut physics
- Achievements
- Sound effects
- Easter eggs
- Advanced animations

## Development Strategy

Build small features and test them before moving on.

AI is an accelerator, not a dependency.

Architecture, decisions, integration, testing and scope control are handled by the team.
